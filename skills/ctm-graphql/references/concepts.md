# CTM concept index

Maps the words users say to CTM's name for the feature, a help article that
explains it, and the GraphQL fields to use. A name that starts with
`account.` is a read under `account(id:)`. A name that starts with a type,
such as `PhoneCall.transcription`, is a field to select on that object in a
read. A name with no prefix is a mutation. A row lists the main operations
for the feature, not all of them: search the schema for the CTM name to find
the others, such as archive and bulk operations, and every argument
("Finding the Right Operation" in the skill). The article links open in a browser; to read an article in an
agent, fetch it by number through the help center API.

"Not in GraphQL" means that no operation exists yet. Permissions, plan
features, and roles still apply to every field. Most descriptions state
them, but some omit a check that CTM still enforces, so a refusal is final
even when the description names no permission. By default, a machine identity can use the reads under `account(id:)` and
the mutations that take `accountId`. It cannot use user, machine identity,
Machine Router, or machine call destination administration
(`MACHINE_NOT_ALLOWED`), or an operation whose description says it
requires human authentication, such as live call listening ("Human
authentication required").
